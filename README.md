# Best Shop - Clothing Store Web Project

A web application and e-commerce frontend designed for a clothing and apparel store. This project manages product display and includes backend connection features structured for local database environments.

## Features

- Product catalog and category display interface.
- Secure local database connection configuration (`conexion.php`).
- Clean separation of assets and code files.

## Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (Legacy / Transition phase)
- **Database:** MySQL / SQLite compatibility structure

## Getting Started (Local Development)

1. Clone the repository to your local environment (e.g., inside your local server directory like XAMPP `htdocs`).
2. Configure your local database and update the credentials inside `conexion.php` using a local user (`root` without password for development).
3. Run your local server to preview and test the store interface.
